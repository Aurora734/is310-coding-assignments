The two APIs I worked with were the [Ghibli.Fandom.com](https://ghibli.fandom.com/wiki/Ghibli_Wiki) API via MediaWiki and an inependent wiki about Ghibli films called [Studio Ghibli API](https://ghibliapi.vercel.app/#). Neither API required any form of authentication, though I still included useragent information as a courtesy. The Studio Ghibli API was formatted as JSON, which made it easy to work with once I had the JSON I wanted to work with, but the API had a very unconventional way of finding it's information that essentially required me to hardcode in the urls. It was also very limited in its information (literally just films, people, locations, species, vehicles, or any one item from any of these 5 categories), and thus, the questions one could ask. The Fandom API required me to parse through html, which could've been much easier had the html been structured better. As for the information held in it, there was far more information and organizational structures to explore. It also had a way to look at a list of all species, but it had way more than simply five categories to look through (ex: it also includes music and staff who work at Studio Ghibli, to name a few). The Studio Ghibli API is similar to a fan wiki, but it's own description does not mention fans being involved in its creation or target audience. It simply says "It was created to help users discover resources, consume them via HTTP requests, and interact with them in whatever way makes sense." The Fandom API on the other hand is access to a corporately-owned but fan-run set of databases, made available via an open source software via the non-profit organization Wikimedia. 


To start, I found each API's list of species found in Studio Ghibli productions. The independent API had a much much shorter list of species (as a fan of Ghibli, I must say it was staggeringly short). I then compared the two APIs' information on dragons in Ghibli. The Studio Ghibli API, once again, had a shockingly limited amount of information, though it oddly highlighted eye color and hair color as important attributes to document. One thing that was on both APIs' pages on dragons was a list of films/appearances. I chose to compare these lists becuase I was very surprised to find the Studio Ghibli API to be missing many (more than half of what the Fandom page listed was missing) films from it's list. It makes me wonder who the Studio Ghibli API was created by/for given its quite odd array of information, which isn't even fully correct.
